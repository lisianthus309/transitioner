첨부 PDF는 1~11페이지가 각각 56행×5열, 마지막 페이지가 40행×5열입니다. 실제 PDF는 병합 표가 아니므로 병합 복원 검증은 생성한 별도 문서에서 수행했습니다.

실제 PDF 대조 정답은 문서의 내장 텍스트 레이어입니다. 독립적인 사람 전사본을 사용한 결과가 아니며, OCR 비교 시 공백만 정규화했습니다. 문자 오인식이나 숫자를 보정해서 맞춘 수치가 아닙니다. 이 결과는 해당 문서와 생성 테스트에 한정되며 모든 복잡한 표의 완벽한 복원을 입증하지 않습니다.

## v0.1.1 — UTF-8 및 작은 셀 인식

- Windows 콘솔 입출력·동결 Python 인터프리터·OCR TSV 파서에 UTF-8을 명시합니다. Excel은 기존 XML 유니코드 저장을 유지하고 한글 글꼴을 지정합니다.
- 작은 셀은 글자 여백을 다듬고 작은 글자를 확대하여 인식합니다. 해당 경로에만 추가 정밀 영어 모델을 적용하며, 대형 표는 회귀 검증을 통과한 기존 모델을 유지합니다.
- Linux: 두 글꼴×두 크기, `1`, `7`, `17`, `71`, `1177`, `7101`, `0107` 총 28건 정확히 일치. 한글 값·한글 XLSX 파일명·선행 0·UTF-8 XML 저장 확인.
- 기존 생성 표 9,000/9,000셀, 한국어 병합 표 33/33셀, 기존 첨부 PDF 3,280/3,280셀(공백 정규화) 일치. 이미지/PDF 일괄 처리 앱 검증 통과.
- 새로 보고된 1→7 오인식 원본은 아직 제공되지 않아 해당 사례의 재현·해결 여부는 미확인입니다. UTF-8 변경으로 OCR 오인식이 모두 해결된다고 보장하지 않습니다.

Windows 수정판 검증: v0.1.1 EXE에서 동결 Python `sys.flags.utf8_mode == 1`, 콘솔 UTF-8, Arial/Times New Roman 글꼴의 숫자 28건, 한글 XLSX 값·파일명·글꼴 검사가 통과했습니다. 공개 ZIP의 비인증 HTTP 200 다운로드, SHA256, CRC, 포함된 버전 및 정밀 모델 해시도 확인했습니다.

## v0.1.2 — 사용자 제공 스크린샷 PDF를 사용한 개발 검증

- 본문 507셀을 별도 전사하여 비교했습니다. 긴 머리글과 판독이 불확실한 이름 1셀은 정답 비교에서 제외했습니다. 원본·정답·학습 체크포인트는 공개하지 않습니다.
- 파일 A: 77/164 → 162/164셀 정확히 일치. `1`을 `7`로 읽는 오류 17건 → 0건. 이름 열의 한글/영문 혼합 2셀은 아직 오인식이 남습니다.
- 파일 B: 296/343 → 343/343셀 일치.
- 영어/숫자 셀 138개로 100회 반복 시범 추가 학습을 수행하고 별도 파일 343셀로 평가했습니다. 전처리 후 기존 모델과 추가 학습 모델의 결과가 같아 학습 모델은 배포하지 않았습니다.
- 개선은 원본 스캔 픽셀 보존, 엑셀 모서리 표시 분리, 셀별 인식, 예측 결과에 따른 열별 언어 선택에서 나왔습니다. 원문 값을 하드코딩하거나 정답으로 치환하지 않습니다.
- 두 파일은 모델 학습/평가에는 분리했지만 처리 방식 개발에 모두 살펴본 자료입니다. 이 수치는 개발 검증 결과이며, 미사용 새 문서에 대한 일반화 정확도는 아닙니다.

## v0.1.3 — 영어 500단어와 모델 재사용

- 합성 단어 500개 × lower/UPPER/Title × 2글꼴 = 3,000개 학습 줄, 4,000회 반복 추가 학습. 추가 4글꼴·2크기 실험도 했지만 선택하지 않았습니다. 원본 사용자 문서는 영어 모델 학습에 사용하지 않았습니다.
- 선택적 적용의 대소문자 포함 정확 일치: 보정 기준용 글꼴 2,990→2,991/3,000, 추가 글꼴 2,993→2,995/3,000, 마지막 추가 글꼴 2,989→2,991/3,000. 관측한 새 오인식은 각각 0건입니다. 학습 단어는 같고 글꼴 조건을 바꾼 시험이며, 모든 새 문서의 정확도를 입증하지 않습니다.
- 학습하지 않은 100단어의 600이미지는 목록 밖 보존 규칙으로 599/600을 유지했습니다.
- 재사용 API와 독립 명령행 실행의 텍스트 72개 비교 및 회색/RGB TSV의 텍스트·좌표·신뢰도 비교가 통과했습니다.
- 사용자 문서의 전체 520셀은 이전 출력과 동일. 약 40.9→4.1초, 91.3→8.2초. 검증 정답 기준 162/164와 343/343은 유지됐습니다.
- 9,000셀 표와 병합 표, 이전 12페이지 문서의 회귀 검증을 수행했습니다. 새 모델은 숫자나 철자를 임의로 바꾸지 않습니다.

Windows 배포 검사(v0.1.3): 실제 라이브러리 사용을 강제한 상태에서 CLI/재사용 API 72개 텍스트 및 TSV 좌표·신뢰도 비교가 통과했습니다. Arial/Times New Roman 500단어×3대소문자×2글꼴 3,000개 검사는 기존 2,993/3,000을 유지하고 새 오류가 0건이었습니다. UTF-8 프로세스 매니페스트와 한글 모델 디렉터리에서도 인식을 확인했습니다.
